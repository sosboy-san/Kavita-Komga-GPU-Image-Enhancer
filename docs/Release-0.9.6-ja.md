# GPUIE 0.9.6 β：変更と検証

## 0.9.5 βからの変更

- Kavitaに水平スライドのページ移動を追加。単ページ・見開き・見開き（マンガ）、左右の読書方向、通常/全画面に対応。
- Kavitaの読書開始時に全画面を試みる設定を追加。ブラウザーのユーザー操作制限によって開始できない場合はネイティブボタンを使用する。
- 読書画面内で詳細設定を開き、閉じると同じ読書ページへ戻る。PCの拡張アイコンは従来のアイコンメニューを表示。読書画面のクイック操作とAndroidの拡張アイコンからは詳細設定を直接開く。
- 詳細設定は横幅600 CSS px以上で中央枠（最大820×680 CSS px）、600未満で全面表示。回転・Fold開閉に追従する。

Kavitaの2つの追加機能は「オプション → 基本設定」で設定し、初期値は両方OFF。
GPUレンダラー、フィルターAPI、Komgaのページ送りは変更しない。アニメーションは独立した一時表示レイヤーを使用する。
縦スクロール・Webtoon・画像分割、動きの抑制設定や方向不明などではスライドを省略する。
更新後は読書タブを一度再読み込みする。

## 配布準備

本体ZIPはextension/直下とライセンス類を収録する。ソースZIPはcommit済みリポジトリから作成する。
追加モジュールは従来の1.0.0のままで、公開APIやその実装を変更しない。
CRXはユーザーが許可した新しい署名鍵で作成する。ZIPとCRXで同じmanifest公開鍵・拡張ID・バージョンを使用する。
CRX署名と内包ZIPの一致を確認し、秘密鍵を公開配布物・ソースZIP・GitHubに含めない。
リリース添付先 uploads.github.com は、この作業環境ではプロキシから403が返る。許可ドメイン追加を環境設定の下書きに保存済み。添付が完了するまでリリースは下書きで保持する。
